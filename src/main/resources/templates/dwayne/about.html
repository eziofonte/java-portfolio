A little introduction

I'm Dwayne Ezail Talavera, a BSIT student at Pamantasan ng Lungsod ng Maynila and a UI/UX designer exploring how things look, feel, and work. I love making interfaces that are clean, thought-out, and intuitive.

Design meets code

For me, a good interface starts with the person using it. I like working through the layout, the details, and the small decisions that make a page easier to find your way around.

From a first sketch in Figma to a working page, I'm learning to connect the details of design with the logic behind them.

Learning by building

My work brings together interface design and development. The Academic Performance Predictor connects a designed interface with sign-in, assessment forms, and private assessment history.

How I approach things

Understand the problem. Explore a few ideas. Build, try it out, and refine. I'm still learning, and each project is a chance to make the next one more considered.
